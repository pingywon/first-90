Plan a company

How it works

First 90 reads a company's public website and writes the plan a new automation lead would bring to day one: the first things worth automating, how to measure each one, what is done by day 30, 60 and 90, and the questions that would prove it wrong.

Six steps, three of them AI

  1. Scout. Opens the homepage and picks up to six telling pages: about, pricing, support, careers, returns, booking.
  2. Reader. Turns them into plain text and removes the menus and footers that repeat on every page.
  3. Analyst. Claude notes concrete signs of manual work, each with a quote from the page it came from.
  4. Planner. Claude ranks 3 to 5 opportunities, each with a metric, a week-one baseline and a 90-day target.
  5. Skeptic. A separate Claude pass challenges every idea, cuts the generic ones, and writes the question that would confirm or kill each one.
  6. Checker. Looks up every quote on its page. Anything not found word for word is marked.

What it can and cannot know

It sees only public pages. It cannot see volumes, internal tools or decisions made on purpose, which is why every plan lists its assumptions and the questions to ask. Treat it as a well-prepared first conversation, not a verdict.

How it is built

  • A Cloudflare Worker reads the site and streams each step to the page as it finishes.
  • Claude Opus 5.5 answers in fixed shapes (structured output), so every plan has the same parts.
  • Sample plans are recorded runs of the same pipeline, timings included.
  • The source code is public.
